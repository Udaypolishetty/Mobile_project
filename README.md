Raju Mobiles — E-Commerce Website

A modern and responsive e-commerce website for Raju Mobiles, designed to showcase and sell mobile phones and accessories through a clean, user-friendly interface.

🚀 Live Demo

Live Website: [(https://raju-mobiles.vercel.app/)]

📌 Overview:
Raju Mobiles is a frontend-focused e-commerce web application built to provide customers with a simple and engaging way to browse mobile products and accessories.
The project focuses on responsive design, reusable components, smooth navigation, and a modern shopping experience.

✨ Features:
🛍️ Product browsing and product showcase
📱 Mobile phones and accessories sections
🔎 Product-focused navigation
📋 Product information and details
📱 Responsive design for desktop and mobile
⚡ Fast development and optimized build using Vite
🎨 Modern UI using Tailwind CSS
🧩 Reusable React components

🛠️ Tech Stack:-
Frontend: React.js
Backend: Django,NeonDB
Styling: Tailwind CSS
Build Tool: Vite

Language: JavaScript

Version Control: Git & GitHub
